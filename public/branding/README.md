# Identidad del taller

Coloca aquí el logo definitivo con el nombre `logo.png` o actualiza `logoPath` en `src/config/taller.config.ts` si utilizas otro nombre.

Recomendaciones:

- Fondo transparente.
- Proporción horizontal o cuadrada.
- Resolución suficiente para impresión.
- No incluir contraseñas, firmas ni información privada en la imagen.
